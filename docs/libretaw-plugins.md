# Плагины libretaw: документация

## Что такое плагин

Плагин — это один файл `.js`. Он может добавлять команды, реагировать на входящие сообщения, менять цвета приложения и хранить свои данные.

Плагин запускается в **изолированной песочнице** (скрытый iframe с `sandbox="allow-scripts"`) и общается с приложением только через объект `libretaw`. Без разрешений он ничего не видит и ничего не может.

Установка: **Настройки → Кастомизация → Плагины → Установить плагин из файла**.

## Формат файла

Файл начинается с блока-манифеста в виде комментария, дальше обычный JavaScript.

```js
/* libretaw-plugin
{
  "id": "example.hello-bot",
  "name": "Привет-бот",
  "version": "1.0.0",
  "author": "Ваше имя",
  "description": "Команды /hello и /dice",
  "permissions": ["commands", "messages.send"]
}
*/
libretaw.commands.add('hello', 'Поздороваться', (args, ctx) => {
  libretaw.chat.send(ctx.chatId, 'Привет, ' + (args || 'друг') + '!');
});
```

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | Уникальный: латиница, цифры, `.`, `-`, `_`, 3–64 символа. Плагин с тем же id заменяет старую версию |
| `name` | да | Название (до 40 символов) |
| `version` | нет | Версия |
| `author` | нет | Автор |
| `description` | нет | Описание (до 200 символов) |
| `permissions` | нет | Список запрашиваемых прав |

Размер файла: до 200 КБ.

## Разрешения

Плагин получает только те права, которые указаны в `permissions` и подтверждены пользователем при установке. Права на чтение и отправку сообщений в приложении помечены ⚠.

| Право | Что даёт |
|---|---|
| `messages.read` | читать входящие сообщения |
| `messages.send` | отправлять сообщения от имени пользователя |
| `chats.read` | список чатов (id, название, тип) |
| `commands` | команды вида `/команда` |
| `storage` | своё хранилище до 100 КБ |
| `toast` | всплывающие сообщения |
| `theme` | менять цвета приложения |
| `profile` | имя и ID пользователя |

## API

Все методы возвращают `Promise`. Если права нет, `Promise` завершается ошибкой `Нет разрешения: <право>`.

```js
libretaw.on('message', fn)                 // входящее сообщение (messages.read)
libretaw.commands.add(name, title, fn)     // команда /name (commands)
libretaw.chat.send(chatId, text)           // отправить сообщение (messages.send)
libretaw.chat.list()                       // [{ id, name, type }] (chats.read)
libretaw.storage.get(key)                  // значение или null (storage)
libretaw.storage.set(key, value)           // сохранить, значение должно быть JSON (storage)
libretaw.ui.toast(text)                    // всплывающее сообщение (toast)
libretaw.theme.setVars({ pri: '#ff5577' }) // цвета (theme)
libretaw.me()                              // { id, name } (profile)
```

### Событие `message`

Приходят только входящие сообщения. Содержимое медиа не передаётся, только признак `hasMedia`.

```js
{ chatId, chatName, chatType, from, text, t, hasMedia }
// chatType: 'person' | 'group' | 'channel' | 'self'
```

### Команды

`libretaw.commands.add('hello', 'Описание', (args, ctx) => { ... })` добавляет команду `/hello`.

Когда пользователь вводит в чате `/hello Вася`, текст **не отправляется** собеседнику, а вызывается функция:

- `args` — текст после команды (`"Вася"`);
- `ctx` — `{ chatId, chatName, chatType }`.

Имя команды: латиница, цифры и `_`, до 24 символов. При вводе `/` под строкой сообщения появляются подсказки. Если команды с таким именем нет, текст отправляется как обычное сообщение.

### Тема

`libretaw.theme.setVars({ ... })` принимает переменные:

`pri, on-pri, pc, on-pc, sec-c, on-sec-c, tc, on-tc, surface, sc-low, sc, sc-high, sc-highest, on-surface, osv, outline, ov, inv, inv-on, err`

Имя можно писать с `--` или без. Значения: `#rrggbb`, `rgb()`, `rgba()`, `hsl()`, `hsla()`. Всё остальное игнорируется. При отключении или удалении плагина цвета возвращаются.

## Ограничения и безопасность

- У плагина нет доступа к странице, чатам, ключам и файлам. Сеть для него закрыта.
- Сообщения от плагина помечаются `· название плагина` рядом со временем.
- Отправка ограничена 10 сообщениями в минуту.
- Хранилище каждого плагина отдельное, до 100 КБ.
- Ошибки плагина показываются в его карточке (Настройки → Кастомизация → Плагины).
- Плагины сохраняются в файл аккаунта вместе с настройками.
- Устанавливайте только плагины, которым доверяете: плагин с правом `messages.read` видит ваши входящие сообщения.

## Примеры

Готовые примеры лежат в папке `plugins/`:

- `hello-bot.js` — команды `/hello`, `/dice`, `/time`;
- `night-sky-theme.js` — тема «Ночное небо»;
- `message-counter.js` — счётчик входящих сообщений и команда `/stats`.

## Отладка

1. Установите файл. Приложение покажет запрашиваемые права.
2. Откройте карточку плагина: там видны права, зарегистрированные команды и последняя ошибка.
3. Чтобы обновить плагин, установите файл с тем же `id`.
4. Если плагин не отвечает, выключите и снова включите его переключателем.
