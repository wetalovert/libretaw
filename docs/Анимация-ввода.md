# Анимация ввода текста

Когда вы печатаете, каждый новый символ появляется прямо в поле ввода с выбранным эффектом. Анимация видна только вам: в сообщение она не попадает и собеседнику не передаётся.

## Где настроить
**Настройки → Кастомизация → Анимация ввода.**
- **Анимация ввода включена.** Выключатель. Когда он выключен, превью над полем не показывается.
- **Список из 10 анимаций.** Нажмите на анимацию, чтобы выбрать её. Сразу проиграется пример.
- **Настройка выбранной анимации.** Для каждой анимации свои значения:
  - **Длительность** (150–1500 мс): сколько длится появление символа.
  - **Сила эффекта** (0–100%): насколько сильно движется или меняется символ.
  - **Цвет:** цвет для анимаций, которые его используют (глитч, радуга). «Цвет темы» возвращает цвет темы.
  - **Движение:** плавно, равномерно, пружина или ступеньками.
  - **Посмотреть** проигрывает пример. **Сбросить эту анимацию** возвращает её значения по умолчанию.

Настройки каждой анимации хранятся отдельно: изменения одной не влияют на другие.

## Десять анимаций
1. **Всплытие:** символ растёт из точки и чуть перескакивает.
2. **Падение:** символ падает сверху.
3. **Подъём:** символ поднимается снизу.
4. **Проявление:** плавное появление.
5. **Из размытия:** символ проступает из тумана.
6. **Глитч:** короткое дрожание.
7. **Волна:** символ подпрыгивает.
8. **Печатная машинка:** символ появляется с мигающим курсором.
9. **Радуга:** цвет проходит по спектру.
10. **Отскок:** символ отскакивает.

## Что важно
- Анимация работает в самом поле ввода в реальном времени. Текст поля не меняется: эффект только показывается.
- Поле отправки устроено как наложение: прозрачное поле для набора и зеркало с анимированными символами под ним. Выделение, перенос строк и прокрутка работают как обычно.
- Анимация не замедляет набор текста: символы появляются сразу, а эффект проигрывается поверх.
