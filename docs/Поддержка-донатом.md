# Поддержка донатом

Владелец сервера или хоста может указать реквизиты для пожертвований. Пользователи увидят их внизу раздела «Настройки».

## Как включить
1. Откройте приложение, режим **Свой сервер** или **Хостинг**, вкладку **Сервер**, войдите паролем администратора.
2. В панели администратора найдите карточку **«Поддержка донатом»**.
3. Включите переключатель **«Показывать реквизиты пользователям»**.
4. Добавьте реквизиты: выберите тип (криптовалюта, карта, счёт, другое), введите название и сами реквизиты, нажмите **«Добавить реквизиты»**. Можно добавить до 20 записей, удалить их можно кнопкой **«Удалить»**.

Выключение переключателя скрывает реквизиты у всех пользователей, сами записи сохраняются.

## Что видят пользователи
Внизу раздела «Настройки» появляется блок:
- заголовок «Поддержи донатом создателя хоста/сервера, реквизиты:»,
- список реквизитов с кнопкой «Копировать»,
- пояснение: «Это зависит от настроек хостеров/серверов: вывод поддержки донатом».

Пока донат выключен или реквизитов нет, блок не показывается.

## Что важно
- Приложение не проводит платежи: оно только показывает реквизиты и копирует их.
- Реквизиты передаются пользователям через приветствие сервера, поэтому после изменения у уже подключённых пользователей блок обновляется сразу, у остальных — при подключении.
- Для хоста список реквизитов также можно менять командами `node libretaw-host.js donate on|off|add|clear|show` (см. Инструкцию 2).
