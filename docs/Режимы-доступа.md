# Режимы доступа: пароль и «только через VPN»

## Пароль для подключения
Администратор включает и выключает пароль в разделе «Свой сервер» или «Хостинг» (переключатель «Пароль для подключения»). Выключенный пароль означает, что подключиться может любой, у кого есть адрес сервера. Состояние хранится на сервере и передаётся в приветствии всем подключающимся.

## Только через VPN
Переключатель «Только через VPN» требует указать VPN-сеть в формате CIDR, например `10.8.0.0/24`. Сервер принимает подключения только с адресов из этой сети; остальные получают ошибку `vpn` и отключаются. При включении режима появляется диалог: «К этому хосту/серверу можно подключиться только через впн, включите пожалуйста впн».

Важно: сервер проверяет адрес, с которого пришло подключение. Это работает, когда клиент получает адрес из VPN-сети (тогда его трафик идёт через VPN-туннель). Если сервер стоит за обратным прокси, адрес будет адресом прокси, и режим нужно настраивать с учётом этого (см. TRUST_PROXY в документации сервера). Режим не защищает от атаки изнутри самой VPN-сети.

## Проверка
`node tests/vpntest.js` запускает настоящий сервер и проверяет: пароль обязателен по умолчанию; после выключения пароль не нужен, после включения снова нужен; неверная сеть отклоняется; подключение извне VPN-сети отклоняется с кодом 4006; изнутри сети принимается; режим выключается.

В интерфейсе проверены: версия внизу настроек, переключатель в панели администратора, текст диалога при включении.

Не проверено: показ диалога на устройстве при получении ошибки `vpn` от настоящего сервера (проверен только код сервера и синтаксис клиента).
