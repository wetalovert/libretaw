# Инструкция 1. Поднять свой сервер libretaw дома

Сервер работает на вашем компьютере или в домашней сети. Данные хранятся у вас, зашифрованные паролем шифрования. Эта инструкция для режима **«Свой сервер»** в приложении.

## Что нужно

- Компьютер, который будет работать постоянно (или хотя бы пока вы пользуетесь мессенджером).
- Node.js версии 18 или новее: https://nodejs.org.
- Папка `server/` из архива libretaw (файлы `libretaw-server.js` и `libretaw-host.js`).

## Шаг 1. Скачайте файлы

Распакуйте архив `libretaw-src.zip`, откройте папку `server/`.

## Шаг 2. Придумайте парольную фразу шифрования

`LIBRETAW_DATA_KEY` — фраза, которой шифруются все данные сервера на диске. Длина не меньше 12 символов. **Без неё данные не восстановить.** Запишите её и храните отдельно от компьютера.

## Шаг 3. Решите, нужен ли пароль подключения

Это главное решение, от него зависит, что увидят пользователи при подключении.

- **С паролем (рекомендуется).** Задайте `LIBRETAW_TOKEN`. Каждое устройство вводит этот пароль при подключении. Приложение показывает: «Пароль задан владельцем сервера. Он обязателен и из приложения не отключается». Пользователи не смогут подключиться без пароля, и вы не сможете отключить его из приложения: только перезапуском сервера с другими переменными.
- **Без пароля.** Не задавайте `LIBRETAW_TOKEN` и `DYNAMIC_PASSWORD`. Тогда подключение возможно без пароля. Приложение покажет: «Владелец сервера пароль не задал: подключение без пароля». Пароль не обязателен **только** в этом случае.

Сервер при запуске без пароля пишет предупреждение: это ожидаемо, если вы сознательно открыли его без пароля. Вариант «без пароля» разрешайте только внутри своей сети или через VPN (шаг 8).

## Шаг 4. Запустите сервер

Откройте терминал в папке `server/`.

**Linux и macOS, с паролем:**
```bash
LIBRETAW_DATA_KEY="длинная-фраза-шифрования" LIBRETAW_TOKEN="пароль-для-подключения" node libretaw-server.js
```

**Linux и macOS, без пароля:**
```bash
LIBRETAW_DATA_KEY="длинная-фраза-шифрования" node libretaw-server.js
```

**Windows (PowerShell), с паролем:**
```powershell
$env:LIBRETAW_DATA_KEY="длинная-фраза-шифрования"; $env:LIBRETAW_TOKEN="пароль-для-подключения"; node libretaw-server.js
```

Переменные:
- `LIBRETAW_DATA_KEY` — парольная фраза шифрования данных. Обязательна.
- `LIBRETAW_TOKEN` — пароль подключения. Если задан, пароль обязателен для всех.
- `ADMIN_TOKEN` — пароль администратора для управления из приложения (см. шаг 7). Без него управление из приложения выключено.
- `VPN_ONLY=1` и `VPN_NET` — режим «только через VPN» (см. ниже).
- `DYNAMIC_PASSWORD=1` — одноразовые пароли вместо постоянного (см. ниже). Тоже делает пароль обязательным.
- `PORT` — порт, по умолчанию 8080. `HOST` — адрес для прослушивания, по умолчанию все интерфейсы.
- `SERVER_NAME` — название сервера, которое видят пользователи.

Когда сервер запущен, в терминале появится строка `libretaw server: http/ws://localhost:8080`. Окно не закрывайте.

Если фраза шифрования не задана, сервер напишет, что она нужна, и завершится.

## Как включить режим «только через VPN»

Режим разрешает подключаться только с адресов из VPN-сети, например `10.8.0.0/24`. Включить его можно двумя способами.

**Способ 1. При запуске сервера.** Добавьте две переменные к команде запуска:
```bash
VPN_ONLY=1 VPN_NET=10.8.0.0/24 LIBRETAW_DATA_KEY="длинная-фраза-шифрования" LIBRETAW_TOKEN="пароль-для-подключения" node libretaw-server.js
```
Если `VPN_NET` не указан или неверен, сервер не запустится и напишет причину. Переменные при запуске имеют приоритет над сохранённой настройкой.

**Способ 2. Из приложения (нужен `ADMIN_TOKEN`).** Откройте **Настройки → Режим работы → Свой сервер → вкладка Сервер**, войдите паролем администратора. В блоке **«Администрирование сервера»** найдите карточку **«Доступ к серверу»**: переключатель **«Только через VPN»** и поле для VPN-сети. Включите переключатель, введите сеть и подтвердите. Появится сообщение: «К этому хосту/серверу можно подключиться только через впн, включите пожалуйста впн».

Выключить режим можно тем же переключателем в приложении или перезапуском без `VPN_ONLY`. Если сервер сохранил режим из приложения, перезапуск без переменных его не сбрасывает: выключите его в приложении.

## Шаг 5. Проверьте шифрование

Команда `node libretaw-server.js check` только сообщает, что шифрование включено; она ничего не проверяет на диске. Как проверить шифрование самостоятельно, описано в `docs/ДОКАЗАТЕЛЬСТВО-шифрования.md`.

## Шаг 6. Проверьте в браузере

Откройте `http://localhost:8080` на этом же компьютере. Должна открыться страница приложения.

## Шаг 7. Управление из приложения (по желанию)

Если задан `ADMIN_TOKEN`, в приложении на вкладке **Сервер** появляется панель «Администрирование сервера». Войдите паролем администратора. В панели:

- **Доступ к серверу.** Строка «Пароль задан владельцем сервера» или «Владелец сервера пароль не задал» — только для информации: пароль, заданный при запуске, из приложения не меняется.
- **Только через VPN.** Переключатель с полем для VPN-сети, например `10.8.0.0/24`. Сервер принимает подключения только с адресов из этой сети. Остальные получают сообщение «К этому хосту/серверу можно подключиться только через впн, включите пожалуйста впн». Подробнее в `docs/Режимы-доступа.md`.
- **Одноразовые пароли.** Если включены, панель показывает текущий пароль и позволяет выпустить новый.

## Шаг 8. Подключите приложение

На каждом устройстве, включая сам компьютер:

1. Откройте libretaw.
2. **Настройки → Режим работы → Свой сервер.**
3. На вкладке **Сервер** введите адрес, например `192.168.1.10:8080`.
4. Если на сервере задан пароль, введите его. Если пароля нет, поле можно оставить пустым: приложение подключится без пароля.
5. Нажмите **Подключиться**. Статус станет «Подключён».

Адрес и пароль можно сохранить, а несколько серверов переключаются одним нажатием.

## Доступ вне дома

Сервер виден только в домашней сети. Для подключения извне:

- **Лучший вариант:** VPN (WireGuard или Tailscale) на сервере и на ваших устройствах. В приложении выберите режим **Удалённая локальная сеть (VPN)**. Включите в панели администратора режим «Только через VPN» с сетью вашего VPN.
- **Публичный адрес с HTTPS:** используйте Traefik из папки `deploy/traefik/` (см. Шаг 6 инструкции 2). Домашний сервер за роутером потребует пробросить порты 80 и 443 на этот компьютер. Порт 8080 не открывайте.
- **Не открывайте порт 8080 в интернет** через роутер без HTTPS и пароля.
## Одноразовые пароли (по желанию)

`DYNAMIC_PASSWORD=1` включает одноразовые пароли. Каждый работает один раз, после входа сервер выдаёт новый. Текущий пароль выводится в терминал и в панели администратора. Постоянный `LIBRETAW_TOKEN`, если задан, продолжает работать.

## Резервная копия

Остановите сервер и скопируйте папку с данными (`data/` внутри папки сервера). Без `LIBRETAW_DATA_KEY` копия не откроется, поэтому храните фразу отдельно.

## Если не подключается

- **«Неверный пароль сервера».** Проверьте `LIBRETAW_TOKEN` на сервере и пароль в приложении.
- **«Подключение только через VPN».** Подключитесь к VPN или снимите режим в панели администратора.
- **Адрес не открывается с другого устройства.** Проверьте, что сервер слушает все интерфейсы (`HOST` не задан или `0.0.0.0`) и что брандмауэр пропускает порт.
- **Приложение не видит сервер.** Убедитесь, что адрес начинается с IP вашего компьютера и порт совпадает с `PORT`.

## Остановка

Нажмите `Ctrl+C` в окне терминала. Данные сохранятся.
