# Инструкция 1. Поднять свой сервер libretaw дома

Сервер работает на вашем компьютере или мини-ПК в домашней сети. Ваши устройства подключаются к нему по адресу сети. Внешних сервисов не нужно.

Все данные на сервере **шифруются обязательно** (AES-256-GCM). Без парольной фразы шифрования сервер не запускается.

Для круглосуточной работы у хостинг-провайдера с резервными копиями читайте **Инструкцию 2**.

## Что нужно

- Компьютер, который работает постоянно (ноутбук подойдёт, но будет засыпать).
- **Node.js 18 или новее.** Проверка: `node -v`. Если команды нет, скачайте LTS-версию с nodejs.org.
- Два файла в одной папке:
  - `libretaw-server.js` — сервер;
  - `libretaw.html` — приложение (сервер отдаёт его по своему адресу).

## Шаг 1. Скачайте файлы

- Файл сервера: в приложении **Настройки → Режим работы → Свой сервер → Сервер → Как поднять свой сервер → Скачать файл сервера**.
- Приложение `libretaw.html` у вас уже есть.

Положите оба файла в одну папку.

## Шаг 2. Придумайте парольную фразу шифрования

Это **не** пароль для подключения. Это ключ, которым шифруются данные на диске. Фраза должна быть не короче 12 символов. Запишите её и храните отдельно: **без неё данные не восстановить**.

## Шаг 3. Запустите сервер

Откройте терминал в папке с файлами.

**Linux и macOS:**
```bash
LIBRETAW_DATA_KEY="длинная-фраза-шифрования" LIBRETAW_TOKEN="пароль-для-подключения" node libretaw-server.js
```

**Windows (PowerShell):**
```powershell
$env:LIBRETAW_DATA_KEY="длинная-фраза-шифрования"; $env:LIBRETAW_TOKEN="пароль-для-подключения"; node libretaw-server.js
```

- `LIBRETAW_DATA_KEY` — парольная фраза шифрования данных (обязательна).
- `LIBRETAW_TOKEN` — пароль, который вводят устройства при подключении (рекомендуется).

Когда сервер запущен, в терминале появится `libretaw server: http/ws://localhost:8080`. Окно не закрывайте.

Если фраза не задана, сервер напишет, что нужна парольная фраза, и завершится.

## Шаг 4. Проверка шифрования

В другом окне терминала, в папке сервера:

```bash
node libretaw-server.js check
```

Должно быть: `Шифрование данных: включено (AES-256-GCM)`.

Если у вас остались данные от старой версии (без шифрования), сервер сообщит, что они не зашифрованы. Зашифруйте их командой (сервер при этом остановлен):

```bash
LIBRETAW_DATA_KEY="длинная-фраза-шифрования" node libretaw-server.js encrypt
```

## Шаг 5. Проверьте в браузере

Откройте **http://localhost:8080**. Должно открыться приложение.

## Шаг 6. Узнайте адрес компьютера в домашней сети

- **Windows:** `ipconfig`, строка «IPv4-адрес», например `192.168.1.10`.
- **Linux:** `ip a`, адрес вашей сети (обычно `192.168.x.x`).
- **macOS:** `ipconfig getifaddr en0` (для Wi-Fi может быть `en1`).

Адрес для приложения: `192.168.1.10:8080`.

## Шаг 7. Подключите приложение

На каждом устройстве, включая сам компьютер:

1. Откройте libretaw.
2. **Настройки → Режим работы → Свой сервер.**
3. На вкладке **Сервер** введите адрес (`192.168.1.10:8080`) и пароль подключения.
4. Нажмите **Подключиться**. Статус станет «Подключён».

Сохранить адрес и пароль, а также несколько серверов можно в той же вкладке.

## Доступ вне дома

Сервер виден только в домашней сети. Для подключения из других мест:

- **Лучший вариант:** VPN (WireGuard или Tailscale) на сервере и на ваших устройствах. В приложении это режим **Удалённая локальная сеть (VPN)**.
- **Не открывайте порт в интернет** через роутер без HTTPS.

## Одноразовые пароли (по желанию)

Вместо постоянного пароля можно включить одноразовые: `DYNAMIC_PASSWORD=1`. Текущий пароль сервер выводит в терминал.

## Резервная копия

Данные лежат в папке `data/` рядом с сервером. Файлы в ней зашифрованы, но сами по себе без парольной фразы бесполезны. Копируйте папку с остановленным сервером, а фразу храните отдельно от копии.

## Если не подключается

- Сервер запущен, окно терминала открыто, адрес и порт верные (`192.168.x.x:8080`).
- Компьютер и устройство в одной Wi-Fi сети.
- Файрвол разрешает порт 8080 (Windows при первом запуске спросит, разрешите доступ в частных сетях).
- Пароль подключения введён верно.
- Пять неверных попыток подряд блокируют адрес на 10 минут.

## Остановка

`Ctrl+C` в окне терминала.
