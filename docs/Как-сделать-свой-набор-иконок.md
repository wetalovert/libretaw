# Как сделать свой набор иконок

Набор иконок меняет рисунки кнопок внутри libretaw. Значок приложения на рабочем столе этим не меняется.

## Что уже есть в приложении
- **7 встроенных наборов:** Стандартные, Контурные, Тонкие, Жирные, Округлые, Двухцветные и Акцентные. Выбираются в **Настройки → Кастомизация → Иконки**.
- **Свой набор.** Его можно сделать самому по шаблону и загрузить в приложение.

## Шаг 1. Скачайте шаблон
В разделе **Иконки** нажмите **«Скачать шаблон для своего набора»**. Получится файл `libretaw-icons-template.json`. В нём 60 иконок. Для каждой указано:
- `label` — где она используется (например, «Отправить» или «Микрофон»);
- `original` — исходная форма в виде контура SVG.

Поля в `icons` пустые. Пустое поле означает, что иконка остаётся стандартной.

## Шаг 2. Нарисуйте иконки
Нарисуйте каждую иконку в любом векторном редакторе (Inkscape, Figma, Krita, Affinity) или возьмите контур из другого набора. Требования:
- размер холста 24×24, иконка в центре;
- один контур на иконку (если рисунок из нескольких частей, объедините их в один путь);
- только прямые линии и кривые, без текста, картинок и эффектов;
- в итоге нужна строка `d` — описание пути (атрибут `d` в SVG).

Чтобы получить `d`, откройте SVG-файл в текстовом редакторе и скопируйте значение атрибута `d="…"`. Вставьте его в поле иконки в шаблоне, без кавычек.

## Шаг 3. Заполните шаблон
Откройте `libretaw-icons-template.json` в текстовом редакторе. Для нужных иконок вставьте строку `d`:

```json
{
  "format": "libretaw-icons",
  "version": 1,
  "name": "Мой набор",
  "icons": {
    "i33": "M2 3l20 9-20 9 3-9z",
    "i35": ""
  }
}
```

- `format` и `version` не меняйте.
- `name` — название набора, которое увидите в приложении.
- Поля, которые не нужны, оставьте пустыми.
- Ключи (`i01`… `i60`) не переименовывайте. Подпись (`label`) и `original` в файле только для справки.

## Шаг 4. Загрузите набор
В **Иконки → Загрузить свой набор (.json)** выберите файл. Приложение проверит его и покажет, сколько иконок принято. Набор сразу становится активным и меняет иконки во всём приложении.

## Правила проверки
Приложение принимает только значения, которые состоят из символов пути SVG: буквы команд (M, L, C, Z и др.), цифры, пробелы, запятые, точки и минусы. Значения длиннее 1500 символов не принимаются. Текст, HTML и скрипты отклоняются. Набор без единой корректной иконки не добавляется.

## Как удалить набор
В списке **Мои наборы** нажмите **«Удалить»** рядом с набором. Если он был активным, приложение вернётся к стандартным иконкам.

## Что ещё важно
- Наборы хранятся на вашем устройстве. Их не получают другие люди.
- Чтобы поделиться набором, просто отправьте другому человеку файл `.json`. Он загрузит его так же.
- Встроенные наборы (контурные, тонкие и т. д.) меняют только стиль линий. Свой набор меняет сами рисунки.
