# Форматирование сообщений

Кроме обычного Markdown (**жирный**, *курсив*, ~~зачёркнутый~~, `код`), в libretaw есть собственные теги. Пишите их прямо в тексте сообщения.

| Тег | Что получится |
|---|---|
| `{dim}текст{/dim}` | затемнённый текст |
| `{big}текст{/big}` | крупный текст |
| `{small}текст{/small}` | мелкий текст |
| `{rainbow}текст{/rainbow}` | радужный текст |
| `{color:red}текст{/color}` | цветной текст: red, blue, green, orange, purple |
| `{spoiler}текст{/spoiler}` | скрытый текст, открывается нажатием |

Теги можно сочетать с обычным Markdown: `**жирный** и {big}крупный{/big}`. Внутри блока кода (`` `…` ``) теги не работают. Незакрытый тег остаётся обычным текстом.

Важно:
- Цвета и размеры заданы списком. Вставить свой HTML или стиль нельзя: весь текст экранируется.
- Старые версии приложения покажут теги как обычный текст. Чтобы текст выглядел правильно у всех, обновите приложение.
