# Как создать свой шрифт для libretaw

libretaw умеет загружать свои шрифты: Настройки → Кастомизация → **Шрифт** → «Загрузить свой шрифт». Подойдёт файл `.ttf`, `.otf`, `.woff` или `.woff2` размером до 2 МБ. Шрифт хранится на устройстве и не уходит на сервер.

## Что должен уметь шрифт

- **Кириллица.** Интерфейс и сообщения на русском. Если в шрифте нет нужной буквы, она покажется другим шрифтом.
- **Цифры и знаки препинания.** Иначе время и даты будут выглядеть непривычно.
- **Лицензия.** Шрифт должен быть вашим или распространяться по лицензии, которая разрешает использование (например, SIL Open Font License). Не загружайте чужие коммерческие шрифты без разрешения.

## Способ 1. FontForge (бесплатная программа, Windows, Linux, macOS)

1. Установите FontForge: https://fontforge.org.
2. **File → New**. Выберите размер em-квадрата 1000.
3. Для каждой буквы: выделите её в таблице символов (двойной клик), нарисуйте контур инструментами «Pen» или «Rectangle» и закройте его.
4. Задайте имя шрифта: **Element → Font Info → Names** (поле «Family Name»).
5. **File → Generate Fonts**. Выберите формат TrueType (`.ttf`) или OpenType (`.otf`). Для компактного файла можно сохранить `.woff2` через **File → Generate Fonts** с опцией WOFF2.
6. Загрузите файл в libretaw.

## Способ 2. Glyphr Studio (в браузере, без установки)

1. Откройте https://www.glyphrstudio.com и создайте новый проект.
2. Рисуйте глифы на сетке, каждую букву отдельно.
3. Экспорт: **Export → TTF** (или WOFF2, если доступно).
4. Загрузите файл в libretaw.

## Способ 3. Собрать шрифт программой (Python)

Для тех, кто хочет управлять формами кодом. В папке `docs/примеры` есть рабочий пример `make_font.py`:

```bash
pip install fonttools
python make_font.py          # создаст my-font.ttf
```

Пример рисует простые блоки вместо букв, чтобы показать принцип. Свои контуры можно задавать в `box()` или через `TTGlyphPen`, а в `letters` добавить кириллические символы (их коды в Unicode: А = 0x0410 и далее).

## Как сжать шрифт в WOFF2 (для меньшего размера)

```bash
pip install fonttools brotli
fonttools ttLib.woff2 compress my-font.ttf      # создаст my-font.woff2
```

## Проверка в libretaw

1. Загрузите файл: Кастомизация → Шрифт → «Загрузить свой шрифт».
2. Если файл не принят, проверьте расширение и размер. Сообщение «Файл не похож на шрифт» означает, что файл повреждён или это не шрифт.
3. Выберите шрифт в списке «Мои шрифты». Текст предпросмотра и сообщения сразу поменяют вид.
4. Перезапустите приложение: шрифт должен остаться.

## Частые проблемы

- **Буквы квадратиками или пустые.** В шрифте нет нужных символов: добавьте их или выберите другой шрифт.
- **Текст слишком мелкий или крупный.** Это свойство шрифта: проверьте метрики (em-квадрат, высоту букв). Масштаб в libretaw не меняется.
- **Файл больше 2 МБ.** Сожмите в WOFF2 или уберите неиспользуемые символы.
