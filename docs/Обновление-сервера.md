# Обновление сервера

Если личные сообщения между людьми не доходят, а у получателя не создаётся чат, на сервере старая версия.

Приложение показывает предупреждение «Сервер устарел», если подключённый сервер не сообщает новые настройки доступа.

Как обновить:
1. Скопируйте новый `server/libretaw-server.js` (и `server/libretaw-host.js`, если вы используете хостинг) на сервер.
2. Остановите сервер и запустите его снова с теми же переменными (`LIBRETAW_DATA_KEY`, `LIBRETAW_TOKEN` и другими).
3. Проверьте: в приложении предупреждения «Сервер устарел» быть не должно, а сообщения между двумя устройствами должны доходить.

Важно: данные сервера (папка `data/`) при обновлении не трогайте, файл `libretaw-server.js` заменяется отдельно.
